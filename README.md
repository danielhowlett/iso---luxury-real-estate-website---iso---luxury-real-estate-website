# HC Construction Website

Professional website for HC Construction, a veteran-owned roofing and construction company serving the Nashville and Springfield, TN area since 2012.

## About

HC Construction specializes in:
- Roofing installation and repair
- Siding installation
- Custom framing
- Home renovations

## Getting Started

> **Prerequisites:**
> The following steps require [Node.js](https://nodejs.org/en/) to be installed on your system.

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

The site will be available at [http://localhost:5000/](http://localhost:5000/)

Build for production:

```bash
npm run build
```

## Technology Stack

- React 18.2.0 with TypeScript
- Vite 6.0.4
- Tailwind CSS 3.4.16
- Framer Motion for animations
- React Router DOM 6.8.1
